# Dodo's Apps

Every study app built together on Claude, in one private repo. Each app is a single self-contained `index.html` in its own folder.

| App | Folder | What it is |
|---|---|---|
| Praxis | `praxis/` | Psychiatry study app: 2,425 questions, spaced repetition, memory hooks, receptor atlas, interview simulations and the Interview Playbook |
| Praxis Clinic | `praxis-clinic/` | Clinical-eye training: Say, Eye, Room and Record modes |
| LUPRAX | `luprax/` | Lebanese University M1 Clinical Psychology hub built on the semester timetable |
| CelestLUBANKM1 | `celestlubankm1/` | Spaced-repetition question bank from the M1 course files, TFP, Clinical Interviewing and a statistics & SPSS course |

## How to open them

1. On this repo's page, tap **Code → Download ZIP** and unzip it.
2. Open `index.html` at the top of the folder for the app menu, or open any app's own `index.html` directly.

Progress is saved in the browser you use. Features that need Claude (cross-device sync, LUPRAX's AI coach) only work in the Claude versions of the apps; everything else works offline.
