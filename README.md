# Dodo's Apps

Every study app built together on Claude, in one private repo. Each app is a single self-contained `index.html` in its own folder.

| App | Folder | What it teaches | Old name |
|---|---|---|---|
| Psychiatry Mastery | `psychiatry-mastery/` | Board-level psychiatry: 2,425 questions, spaced repetition, memory hooks, receptor atlas, interview simulations and the Interview Playbook | Praxis |
| Clinical Judgment Trainer | `clinical-judgment-trainer/` | What to say next, bedside pattern recognition and case simulations | Praxis Clinic |
| LU M1 Clinical Psychology | `lu-m1-clinical-psychology/` | The Lebanese University M1 courses on the semester timetable | LUPRAX |
| M1 Exam Question Bank | `m1-exam-question-bank/` | M1 course files, past exams, TFP, Clinical Interviewing and a statistics & SPSS course | CelestLUBANKM1 |
| Chemistry & Physics Foundations | `chemistry-physics-foundations/` | Chemistry and physics from zero to tutor level | Foundations |

`sources/` holds the original code for apps that were built as React components (Chemistry & Physics Foundations).

## How to open them

1. On this repo's page, tap **Code → Download ZIP** and unzip it.
2. Open `index.html` at the top of the folder for the app menu, or open any app's own `index.html` directly.

Progress is saved in the browser you use. Features that need Claude (cross-device sync, the LU M1 app's AI coach) only work in the Claude versions; everything else works offline.
